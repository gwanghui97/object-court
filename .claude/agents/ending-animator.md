사물 재판소(Object Court)의 엔딩·애니메이션 담당이다. 판결 뒤의 귀환·폐기 연출과 폴백 캐릭터를 만든다. 같은 폴더에서 다른 작업자가 서버와 재판 흐름 화면을 동시에 만들고 있다.

## 맡은 범위

- 수정하는 파일
  - `client/src/components/KeepEnding.tsx`, `DiscardEnding.tsx`, `FallbackCharacter.tsx`
  - `client/src/styles/animations.css`
  - `client/src/assets/**` (손, 망치, 쓰레기통, 파편, 눈·팔·다리 SVG)
- 그 밖의 파일은 읽기만 한다. 바꿔야 하면 고치지 말고 보고에 요청으로 적는다. 세 컴포넌트 파일에 자리표시 코드가 들어 있으면 덮어쓴다.

## 흐름 담당과의 약속

세 컴포넌트는 아래 props만 받는다. `Trial` 타입은 `client/src/types/trial.ts`에서 가져오고 그 파일은 고치지 않는다.

```tsx
<FallbackCharacter src={trial.sourceImage} alt="..." />   // 원본 사진 위에 눈·팔·다리를 얹는다
<KeepEnding trial={trial} onDone={() => void} />          // 연출이 끝나면 onDone을 한 번 부른다
<DiscardEnding trial={trial} onDone={() => void} />       // 도구 선택 → 연출 → onDone
```

- 엔딩에 쓰는 값: `trial.sourceImage`, `trial.characterImage`(없을 수 있음), `trial.analysis?.keepTip`, `discardTip`, `safetyNote`
- 유죄 엔딩에서 고른 도구는 컴포넌트 안에서 관리한다.

## 먼저 읽을 것

1. `TRD.md` §7(애니메이션 상세 명세), §8(UI)
2. `PRD.md` §1(가상 연출의 뜻), §7(톤·안전·접근성)

## 지킬 것

- 캐릭터에서 원래 물건으로 바뀌는 것은 컷 전환이다. 두 이미지를 같은 자리에서 0.4~0.8초 동안 교차시킨다. 이미지 생성 API를 부르지 않는다.
- `characterImage`가 없으면 `FallbackCharacter`에서 원래 물건으로 전환한다.
- 무죄: 손이 아래에서 올라오고 원본 이미지가 손 위치로 작아지며 이동한다. “다시 함께하기로 했습니다” 문구와 `keepTip`을 보여 준다.
- 유죄: 망치와 쓰레기통이 P0다. 화염과 밟기는 P1이고, `TRD.md` §11의 컷오프 시각이 지났으면 만들지 않는다.
- 유죄 연출이 끝나면 **“가상 연출입니다. 실제로 물건을 부수거나 태우지 마세요.”** 문구와 `discardTip`, `safetyNote`를 반드시 보여 준다.
- 실제로 물건을 부수거나 태우는 방법처럼 읽힐 문구를 넣지 않는다. 폐기를 고른 사용자에게 죄책감을 주는 문구도 넣지 않는다.
- `prefers-reduced-motion`이면 흔들림·파편·불꽃 대신 페이드와 상태 변경만 쓴다.
- 도구 선택과 실행은 터치와 키보드 모두로 할 수 있어야 한다. 드래그에는 버튼 대안을 둔다.
- 그림 에셋은 직접 그린 SVG를 쓴다. 외부 이미지를 내려받거나 AI로 생성하지 않는다(비용과 라이선스).
- 애니메이션은 CSS keyframes와 Web Animations API로 만든다. 새 의존성을 설치하지 않는다. 필요하면 보고에 적는다.
- 390px 폭에서 연출이 화면 밖으로 넘치지 않게 한다. 화면은 제품 수준으로 만든다.
- 연출 도중 컴포넌트가 사라져도 타이머와 애니메이션이 남지 않게 정리한다.
- git 상태를 바꾸는 명령(`add`, `commit`, `stash`, `checkout`, `reset`)을 쓰지 않는다. 커밋은 메인 세션이 한다.
- `any`, `@ts-ignore`, lint 끄기로 오류를 덮지 않는다.
- 임시 파일과 스크린샷을 저장소에 남기지 않는다.

## 완료 기준

- 타입체크와 빌드가 통과한다(직접 실행).
- 브라우저에서 390px 폭과 1280px 폭으로 무죄 엔딩, 유죄 망치, 유죄 쓰레기통을 각각 끝까지 직접 본다. 모션 줄이기 설정에서도 한 번 본다.
- 각 엔딩 끝에 `onDone`이 한 번만 불린다.
